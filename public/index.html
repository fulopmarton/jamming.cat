jamming.cat: a cat that jams in your terminal

$ curl {{host}}

Colors
Size

Run it in a terminal and the cat jams along until you press Ctrl+C.

Full 24-bit color, which most modern terminals support. The cat takes up 48 columns and 24 rows.

Options
They're just parts of the address, so you can type them too: /party, /256, /ascii, /small, /big. Combine them like curl {{host}}/party/big.
Windows PowerShell
Type curl.exe instead of curl.
wget or HTTPie
wget -qO- {{host}} or http --stream {{host}}

The cat is the catJAM emoji, from emoji.gg. Inspired by parrot.live.
