curl {{host}}

Run it in a terminal and the cat jams along until you press Ctrl+C.

Change the look

curl {{host}}/party
Rainbow cat that switches color on every head bob.
curl {{host}}/256
Fewer colors, for terminals without 24-bit color support.
curl {{host}}/ascii
Plain text characters. Works in any terminal and uses the least data.
curl {{host}}/small
32 columns wide. /big is 64. The default is 48, which fits an 80×24 window.

Options combine, like curl {{host}}/party/big.

On Windows PowerShell, type curl.exe instead of curl. With wget, use wget -qO- {{host}}.
